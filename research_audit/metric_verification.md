## B2. Reconstructed classification metrics (held-out official test set, n = 484: 242 DME / 242 Normal)

Source predictions: `research_outputs/data/test_predictions_<model>.csv`. These were regenerated on 2026-10-27 by a fresh forward pass of each unmodified checkpoint (CPU, torch 2.14, timm 0.9.7), because the project never saved per-image outputs. They are **independently reconstructed** from the checkpoints. They are not the original in-memory outputs, but they agree with every aggregate saved in `metrics.json` (below).

| ResNet-50 | 241 | 0 | 242 | 1 | 0.9979 (0.9884–0.9996) | 1.0000 (0.9843–1.0000) | 0.9959 (0.9770–0.9993) | 1.0000 (0.9844–1.0000) | 0.9979 (0.9938–1.0000) | 1.0000 | 1.0000 | 0.0020 | 0.0084 |

CI methods: Wilson score for proportions; class-stratified percentile bootstrap (B = 2000, seed 42) for F1. **AUROC CI: DeLong. When classes are perfectly separated (AUROC = 1), the DeLong variance is exactly 0, so the interval [1.000, 1.000] is degenerate and does not represent real uncertainty.** A percentile bootstrap is degenerate for the same reason. A meaningful AUROC interval is given only for the larger supplementary set (`leakage_audit.md` §6).

## B5. Calibration and explainability

Test set, temperature **refit on the training-time validation split** (`calibration_summary.csv`):

| Model | T refit | Brier raw → cal. | Log loss raw → cal. | ECE₁₀ raw → cal. | Val ECE₁₀ raw → cal. |
|---|---|---|---|---|---|
| EfficientNet-B3 | 1.549 | 0.00129 → 0.00136 | 0.00404 → 0.00634 | 0.00284 → 0.00524 | 0.0133 → 0.0054 |
| EfficientNet-B0 | 1.557 | 0.00223 → 0.00223 | 0.00765 → 0.00982 | 0.00384 → 0.00735 | 0.0132 → 0.0031 |
| ResNet-50 | 1.121 | 0.00203 → 0.00202 | 0.00844 → 0.00837 | 0.00226 → 0.00209 | 0.0038 → 0.0020 |
| B3 + LS 0.05 | 0.625 | 0.00269 → 0.00159 | 0.0326 → 0.0090 | 0.0306 → 0.0070 | 0.0364 → 0.0078 |

Original, superseded temperatures (fitted on the contaminated split), for reconciliation: B3 T 0.917, ECE 0.00284 → 0.00268; B0 T 1.019, 0.00384 → 0.00389; ResNet-50 T 0.881, 0.00226 → 0.00232; B3+LS T 0.479, 0.0306 → 0.0035. These match the reported ECE values.

- Neither temperature was fitted on the test set.
- On the held-out validation set, refit scaling improves ECE for every model. On the test set it does not for B3 and B0 (ECE and log loss get worse): the models are over-confident on validation patients (T > 1 softens them) but the test set is easier, so softening costs calibration there. This is further evidence of the validation/test shift (`leakage_audit.md` §4).
- The README wording "calibrated via temperature scaling (ECE 0.0028 → 0.0027)" is based on the superseded temperature and should not be repeated.
- Label smoothing makes raw probabilities under-confident; temperature scaling corrects that on both validation and test. This is the only case with a clear, consistent effect.
- Calibration is a monotonic transform here, so it **cannot change AUROC** (confirmed: identical).
- 482 of 484 (B3, B0), 483 of 484 (ResNet-50) and 474 of 484 (B3+LS) raw test predictions fall in the two outermost 0.1-wide bins (`reliability_bins.csv`). The eight middle bins hold 0–2 images each for the three main models, so the reliability diagram says almost nothing about calibration at intermediate probabilities. ECE on n = 484 with near-perfect accuracy carries very little information.

Grad-CAM (`explain.py`): the target layer is `model.conv_head`. Examples are chosen deterministically: the most confident correct DME, the most confident correct Normal, and the worst-margin misclassification at threshold 0.5. That is a documented rule, but it shows extreme cases only, not representative ones. The randomisation check randomises only `model.classifier`, and the mean correlation is −0.117. This shows that the heatmap depends on the classifier weights. It does **not** show that the highlighted regions are clinically meaningful. No Grad-CAM figure is regenerated in this audit.
