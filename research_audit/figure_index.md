# Figure index (Phase C)

Data: `research_outputs/data/literature_comparison.csv` (built by `research_outputs/scripts/20_build_comparison_data.py`). Figures: `research_outputs/scripts/21_plot_comparison_figures.py`. Each figure exists as .png (300 dpi) and .pdf in `research_outputs/figures/`. Every comparator value was checked against its paper's PDF (read 2026-10-31/11-01); no bar is hatched. Highlighted copies of the four papers, with an index of every highlighted passage and which figure it feeds, are in `research_audit/source_highlights/`.

- **F1_comparable_results** - Accuracy, sensitivity, specificity and AUROC for category A/B sources on shared axes (zero-based panel plus labelled 0.95-1.00 zoom), Wilson 95% CIs where n is known, with the note that this project and P2 share the same 242 DME test images. CSV rows: `proj_b3_050`, `proj_b3_refit`, `P2`, `P4`.
- **F2_test_set_composition** - Test-set size and DME count per source, with the P3 250-vs-242 discrepancy annotated (arithmetic from the papers shown, cause not established) and official-split vs external sets labelled; includes category C because it shows composition, not performance. CSV rows: `proj_b3_050`, `P1_int_comp`, `P1_ext`, `P2`, `P3`, `P4_comp`.
- **F3_ci_overlap_sensitivity** - Horizontal Wilson 95% CIs for sensitivity (zero-based and zoomed panels), sorted by point estimate, vertical reference line at this project's B3@0.5 estimate, no cross-study test. CSV rows: `proj_b3_050`, `proj_b3_refit`, `P2`, `P4`.
- **F4_reporting_checklist** - Count of seven reporting criteria each source confirms as reported (stacked, plus per-criterion panel), scored only on what each text states, all four papers read in full; includes category C because it shows reporting, not performance. CSV rows: `proj_b3_050`, `P1`, `P2`, `P3`, `P4` (columns `rep_*`).
- **F5_architecture_comparison** - This project's EfficientNet-B3, EfficientNet-B0 and ResNet-50 at threshold 0.5 with Wilson 95% CIs, annotated with the 2 images on which any pair of models disagrees. CSV rows: `proj_b3_050`, `proj_b0_050`, `proj_r50_050`.
- **F6_contextual_noncomparable** - Contextual only, on separate axes from F1/F3: this project beside P1 Table 5 (trained on 1,000 + 1,000 images, test set not stated), P1 Table 8 (external Beijing Cirrus set, 4-class model, DME one-vs-rest) and P3 (pooled negative class), with the caption "These bars are not a ranking". CSV rows: `proj_b3_050`, `P1`, `P1_ext`, `P3`.
